# Roblox Elemental Battlegrounds Custom Characters and Movesets

This project provides custom characters and movesets for the Roblox game Elemental Battlegrounds. It includes scripts for Eternamax Eternatus and Hoopa Unbound, enhancing the game with unique Pokémon and their signature moves.

## Install

1. Clone the repository to your local machine.
2. Copy the desired script files from the `src` directory.
3. Place the script files in the appropriate folder in your Roblox game.

## Use

1. Open your Roblox game in Roblox Studio.
2. Navigate to the folder where you want to add the custom characters and movesets.
3. Paste the script files into the folder.
4. Run the game to see the custom characters and their movesets in action.
